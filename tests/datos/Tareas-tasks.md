# Tareas

> [!tip] Cómo añadir tareas
> - En **cualquier nota** del vault: una casilla de tarea seguida de `📅 AAAA-MM-DD`. Esta página las reúne todas.
> - Sin escribir emojis: `Ctrl+P` → **Tasks: Create or edit task** abre un formulario con calendario, prioridad y repetición.
> - **Símbolos:**
>   - 📅 vencimiento · ⏳ programada (cuándo te pones) · 🛫 inicio · 🔁 repetición (`every week`);
>   - prioridad: ⏫ alta · 🔼 media · 🔽 baja.
> - Al marcar una tarea como hecha se añade ✅ con la fecha. Si se repite, se crea la siguiente.
